## Downloaded on request, not bundled

| Tool | Version | License | Source |
|---|---|---|---|
| untrunc (Windows only) | the author's rolling `latest` build, recorded by commit | GPL-2.0-or-later (its bundled Zeranoe FFmpeg 3.3.4 libraries: GPL-3.0-or-later) | https://github.com/anthwlock/untrunc |

untrunc is not part of the installer. When you use Repair damaged video, the app offers to download the author's own release from github.com, checks it against the sha256 GitHub lists for it, and keeps it in the app's data folder (`tools\untrunc\`). Its source, and that of the libraries in its package, is at the link above.

The FFmpeg build is GPL-licensed because it includes x264 and x265. Its source is the FFmpeg commit above plus BtbN's build scripts at that autobuild tag, which pin every library built into it. Copies of the source for each build are attached to every release of this project (Windows: `ffmpeg-source-d59078794d.tar.gz` and `ffmpeg-builds-autobuild-2026-11-20-12-40.tar.gz`; Mac: `ffmpeg-9.0.2-source.tar.xz` and `ffmpeg-apple-silicon-v9.0.2-1.tar.gz`), and are also available on request.

The full licence texts for everything above, and for the Rust and npm libraries inside the app, ship with the installer and are shown in Settings > About > Open-source licences. They are generated by `npm run licenses` into `src-tauri/resources/licenses/NOTICES.txt`; the texts for the bundled programs are in [licenses/tools/](licenses/tools/).
