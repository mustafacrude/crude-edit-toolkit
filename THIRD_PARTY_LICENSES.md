# Third-party tools bundled with Crude's Edit Toolkit

Exact versions and download hashes are pinned in [tools/manifest.json](tools/manifest.json).

| Tool | Version | License | Source |
|---|---|---|---|
| yt-dlp | 2026.10.21 | Unlicense | https://github.com/yt-dlp/yt-dlp |
| Deno | 2.9.8 | MIT | https://github.com/denoland/deno |
| FFmpeg (ffmpeg, ffprobe) | n9.0.2 + 35 commits (`9a9b70bb8c`), BtbN Windows GPL build `autobuild-2026-10-24-13-02` | GPL-3.0-or-later | https://github.com/BtbN/FFmpeg-Builds (source: https://github.com/FFmpeg/FFmpeg/tree/9a9b70bb8c) |
| ExifTool | 13.59 | Artistic-1.0-Perl or GPL-1.0-or-later | https://exiftool.org |
| TwitchDownloaderCLI | 1.56.5 | MIT | https://github.com/lay295/TwitchDownloader |

The FFmpeg build is GPL-licensed because it includes x264 and x265. Its source is the FFmpeg commit above plus BtbN's build scripts at that autobuild tag, which pin every library built into it. Copies of both are attached to every release of this project (`ffmpeg-source-9a9b70bb8c.tar.gz`, `ffmpeg-builds-autobuild-2026-10-24-13-02.tar.gz`), and are also available on request.

The full licence texts for everything above, and for the Rust and npm libraries inside the app, ship with the installer and are shown in Settings > About > Open-source licences. They are generated by `npm run licenses` into `src-tauri/resources/licenses/NOTICES.txt`; the texts for the bundled programs are in [licenses/tools/](licenses/tools/).

The macOS FFmpeg build is not chosen yet; this file will be updated when it is.
